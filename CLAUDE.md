# Palo Alto — Claude Instructions

## What this project is

Homework assignment project for **Gal Ganon**. Static site hosted on GitHub Pages via `galganonn/Palo-Alto`.

## Stack

- Vanilla HTML/CSS/JS
- No npm, webpack, bundlers, or anything similar
- Fonts via Google Fonts or Fontshare (CDN)
- No external JS libraries

## File structure

```
/Palo-Alto/
├── index.html          ← Main page
├── uploads/            ← Images and assets
└── CLAUDE.md           ← This file
```

## Git

- Main branch: `main`
- Remote: https://github.com/galganonn/Palo-Alto
- GitHub Pages: enabled on `main` branch root
- Commit before every significant change
- Never push without explicit user approval

## Code conventions

- Vanilla HTML/CSS/JS only — no frameworks
- Styles inline or in a `<style>` block in the HTML
- All JS in a `<script>` block before `</body>`
